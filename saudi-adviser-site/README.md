# Saudi Adviser
Static Arabic legal-information site for Saudi Arabia.

## SEO / AdSense gate
- Unique Arabic content with official-source links
- Clear About, Editorial Policy, Methodology, Corrections, Privacy, Terms, Advertising Disclosure
- Canonical URLs, robots.txt, sitemap.xml
- 1200x675 original images and max-image-preview:large
- No AdSense code before approval; add publisher ID and ads.txt only after Google supplies them
- Contact form intentionally stores drafts locally until a secure backend/email is connected
- No claim that the site is a law firm or government entity

## Deployment
Static root. Vercel/Netlify can serve this directory directly.
